# Online Food Ordering System

## 📌 Project Title

Online Food Ordering System (Day 1 Progress)

---

## 📖 Project Overview

This project is a basic **Online Food Ordering System** being developed using **PHP, HTML, CSS, and MySQL database**.

As of now, the project is in its early development stage (Day 1). It currently includes only the **login system** and a basic **admin panel structure**. More features will be added gradually.

---

## ✅ Completed Features (Day 1)

* User Login Page (basic authentication UI)
* Admin Login Page
* Admin Dashboard (basic layout only)

---

## 🚧 Work in Progress

* Database integration for user authentication
* Food menu management system
* Order placement system
* Cart functionality
* Payment system integration (test API module planned)

---

## 💳 Payment System (Planned)

A test payment module will be added in future development using an API key structure.
This will later be replaced with real payment gateways such as:

* Local payment systems (eSewa / Khalti)
